# Guión de demostración — 5 minutos

1. **0:00–0:45**: presentación de roles y apertura de caja.
2. **0:45–1:45**: registro de entradas y salidas, validación de montos y cálculo de saldo.
3. **1:45–2:45**: desconectar la red, registrar movimientos offline y revisar la cola.
4. **2:45–4:00**: restaurar conexión, sincronizar con el ERP y mostrar resultados/duplicados.
5. **4:00–5:00**: cierre de caja, resumen y preguntas.
