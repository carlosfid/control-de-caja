# Decisiones técnicas

- **TypeScript**: comparte contratos y reglas entre cliente y servidor con tipado fuerte.
- **React + Capacitor**: permite una misma interfaz web distribuida como aplicación Android.
- **Dexie**: ofrece almacenamiento offline indexado sobre IndexedDB con transacciones.
- **Fastify**: servidor ligero y rápido para el simulador ERP.
- **SQLite**: persistencia local simple, portable y adecuada para la demostración.
- **npm workspaces**: simplifica la instalación y ejecución de las áreas del monorepo.
